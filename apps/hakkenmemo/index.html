発見の手帳

ひとつの着想を、ひとつのメモに。

日常の発見、ふと浮かんだ考え、あとで育てたいアイデア。ひとつずつ残して、探して、つなげていくためのメモアプリです。

App Store公開準備中
Features

シンプルに記録し、
後から見つける。

01 / WRITE

一メモ一項目

ひとつのメモに、ひとつの発見。見出しと本文で考えを残します。

02 / FIND

全文検索と索引

本文の言葉から探す。見出しや索引語から辿る。探し方は自由です。

03 / CONNECT

メモを関連付ける

別々の発想をつなぎ、関連するメモを行き来できます。
